### Featured project: [NFA Visualizer](https://bquant90.github.io/nfa-visualizer/)

[![NFA Visualizer: the machine reading "1101", with the current states lit up and a plain-English caption](https://bquant90.github.io/nfa-visualizer/docs/screenshot.png)](https://bquant90.github.io/nfa-visualizer/)

I rebuilt a Theory of Automata class project, a command-line Python program, into a free web app that teaches how these machines work in a way anyone can follow. You load a machine, type a string, and step through it, with every step explained in plain words.

- **Planned before building:** six phases, acceptance criteria for every step, and a [decisions log](https://github.com/bquant90/nfa-visualizer/blob/main/docs/DECISIONS.md) of design choices and the alternatives I passed on.
- **Proven, not assumed:** checked line by line against the original Python program as an answer key, on every test file and thousands of random machines, with zero differences.
- **Built for everyone:** works on phones, in dark mode, with screen readers, and with browser translation.
- **Reviewed twice:** built with Claude, and independently reviewed by Gemini. I decided which findings were real before making any changes.
